# Archived copy of the fixed-slot four-module firmware

Historical copy of the former active `four-module-full-scan` branch. It is retained for provenance and is not the final-report deployment source. Use `../../../active/four-module-variable-spi` for the final project.

The branch uses ESK v4, two 16 x 16 FSR arrays per STM32, fixed 1044-byte HOST SPI slots, a Teensy 4.1 MUL1 v2 bridge and FULL/DELTA/SPATIAL parsing.
