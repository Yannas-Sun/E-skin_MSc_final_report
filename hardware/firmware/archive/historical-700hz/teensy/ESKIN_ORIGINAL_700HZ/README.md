# Original Teensy-direct 700 Hz reproduction

This experiment preserves the original Teensy 4.1 pin map and sensor drivers
from `previous/src/Eskin`. It reproduces the active-stream `loop()` formerly
generated by the legacy software, with a nominal 700 Hz start interval.

Each `ESKN` packet is 1,132 bytes:

- 4-byte `ESKN` marker
- 4-byte accelerometer timestamp
- 4-byte FSR timestamp
- 96 bytes: 16 accelerometers x 3 axes x `int16_t`
- 1,024 bytes: two complete 16 x 16 FSR layers as `uint16_t`

The 700 Hz macro is a requested start interval, not proof of measured rate. If
one acquisition plus USB write exceeds 1,428 us, the loop runs as fast as it
can and misses the nominal schedule without reporting a deadline miss.

The original ADC path uses 10 MHz Mode-0 hardware SPI, SCLK-driven conversion,
no EOC polling, and no explicit MUX settling delay.
