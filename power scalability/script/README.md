# Power scripts

Scripts use project-relative paths and discover the project root from their own location.

- Main/pipeline/: current voltage, ZERO/MAX and retest compilation.
- Main/figures/: report figure generators and plotting style.
- Main/intake/: dated photograph transcription and supplements.
- Main/tests/: provenance and coverage checks.
- Main/legacy/: historical Power 2.1 reproduction.

Run from the power scalability directory. See Main/README.md for the current entry points.
