# Main power scripts

Current inputs are under DATA/raw/; derived outputs are under DATA/analysis/ or DATA/reference/.

- pipeline/: current voltage, ZERO/MAX and retest summaries.
- figures/: report and historical figure generators.
- intake/: photograph transcription and supplement reviews.
- tests/: source, coverage and provenance checks.
- legacy/: Power 2.1 comparison.

Scripts resolve paths from __file__ and do not require a drive letter. Run them from the power scalability directory.
