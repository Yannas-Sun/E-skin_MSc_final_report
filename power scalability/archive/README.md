# Archived power-scalability material

Nothing in this directory was deleted. Items here were moved out of the active paper workflow because they are superseded, generated cache, or historical notes that are not required to reproduce the current report.

| Subfolder | Contents and reason for archiving |
|---|---|
| legacy_analysis/ | The former CSV-only analysis under `archive/legacy_analysis/DATA_analysis/` and its standalone analyser/validator scripts. It predates the current provenance-checked matrix and is kept for comparison. |
| historical_documents/ | The previous Chinese top-level README and three Chinese planning/log documents. English active guides now describe the current evidence; the originals are preserved here. |
| historical_snapshots/ | all_power_review_20260907_history/ and the retired preview mean-drop heatmap, both dated snapshots rather than current evidence. |
| generated_cache/ | Python __pycache__ bytecode generated during earlier runs. |

Versioned report outputs and their upstream manifests remain in DATA/ when the current appendix or a later SHA-256 manifest still references them. This preserves the paper's audit trail even when a release is older than the current figure export.
