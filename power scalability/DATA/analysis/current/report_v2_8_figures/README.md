# Report v2.8 figure release

This folder contains the eight audited figure families used by the Power appendix and related discussion: current/power scaling, source/module voltage scaling, module voltage drop, module-count drop, single-module screening, branch-current balance, temperature scaling and independent-current prediction.

Every family has PDF, PNG and SVG exports. figure_manifest.json records the semantics, dimensions, input hashes and script hashes. Use the PDF/SVG files for publication and the PNG files for quick inspection on GitHub.

The figures are descriptive. Error bars or spread markers represent combinations at a fixed module count where stated; they do not establish independent repeatability or extrapolated supply capacity.
