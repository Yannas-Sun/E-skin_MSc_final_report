# Accepted voltage review

This folder contains the accepted pointwise voltage view for the continuous-read records, including the documented M0 supply-connector contact event and its user-confirmed replacement point. It provides the accepted configuration table, module-level table, coverage and source summary used by later Power compilations.

The readings are sequential DMM observations. The reported range is not a transient bound, and a pointwise retest is not a new complete configuration repeat. Photograph relocation and hash checks are recorded in ../../provenance/path_relocation_20260907
