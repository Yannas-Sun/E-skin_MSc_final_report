# Power experiment records

Canonical source records for the report's power experiments.

- transmission/: continuous USB acquisition records.
- no_transmission/: blocked-standby records.
- Each record contains the original YAML fields and associated photographs.
- current_temperature_supplements/: later user-confirmed current and temperature supplements.
- Do not edit raw files in place. Current summaries are under DATA/analysis/current/; provenance is under DATA/analysis/provenance/.

The records document static readings at configured 200 Hz. They do not prove transient supply capacity, thermal equilibrium or independent hardware repeats.
