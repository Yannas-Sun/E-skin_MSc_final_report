# Power photographs

This folder preserves the separate blocked-standby photograph set and one historical setup image. It is kept for traceability and visual context; it is not combined with the continuous USB-read YAML matrix in ../DATA/raw/canonical/power_experiment_records/.

The No_transmission/ tree is grouped by recorded module count and combination. The continuous-read source photographs used by the paper are stored beside their YAML records under ../DATA/raw/canonical/power_experiment_records/transmission/ and its targeted retest folders.

Photograph filenames are original camera names. They should be treated as source evidence, not as proof of protocol frequency, firmware identity, timing, or a transient electrical limit.
