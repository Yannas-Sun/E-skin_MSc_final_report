# Blocked-standby photographs

The JPEGs in this directory were copied from `power scalability/photos/No_transmission/` into the existing module and load folders when their displayed voltage/current extrema could be matched to the corresponding YAML record. The large central number on a photograph is an instantaneous reading; it is not compared with the YAML average. Matching uses the photograph's `MAX` and `MIN` fields against the YAML extrema (for N=2 M2-M3 current, `peak_instant_mA` is the recorded maximum field).

Thirty-eight photographs exactly match current YAML extrema. One additional N=4 M1-current photograph is placed beside the ZERO record as a near-match: its displayed maximum is 16.23 mA, matching the YAML, while its displayed minimum is 8.164 mA versus 8.160 mA in the YAML. Ten photographs are retained under `historical_unmatched_20260831` or `historical_unmatched_1st_20260831` because their extrema do not match any current YAML record.

N=1 source images have no load label; where ZERO and MAX YAML values are identical, the image is placed under the ZERO folder with that limitation recorded. The original `photos/No_transmission/` files remain unchanged.
