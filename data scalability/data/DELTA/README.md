# DELTA data

The DELTA set contains 45 zero-load recordings and 21 dynamic recordings. All 45 zero-load windows pass the main-window audit. Of the dynamic recordings, 16 pass and 5 remain CHECK; five complete passing batches (15 windows) form the dynamic performance subset.

- Zero-load matrix: Zero_load/README.md
- Dynamic batches: Dynamic_load/README.md
- 45 selected zero-load windows: primary_matrix.csv
- 15 selected dynamic windows: dynamic_analysis_selected.csv
- All 66 DELTA records: ../run_index.csv

The original GUI status is retained beside the independent audit fields. ESKF synchronisation cost is included in measured byte totals. Dynamic labels corrected from acquisition metadata are represented in the derived index; source logs and summaries remain unchanged.
