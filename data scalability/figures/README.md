# Data figures

This directory contains source exports and diagnostics for the data-scalability figures.

Report-linked figures:
- figures/data/v2_11/full_model_validation.pdf
- figures/data/v2_9/data_length_traces.pdf

Other exports are intermediate theory panels, protocol diagrams and diagnostic views. They are retained only when needed to trace a report figure. USB theory uses the 480 Mbit/s reference; HOST SPI uses the 10 MHz reference. Measurements stop at N=4; extensions are conditional projections.
