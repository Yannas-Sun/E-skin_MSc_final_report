## Current selection

The indexed campaign contains 114 recordings: 48 FULL zero-load, 45 DELTA zero-load and 21 DELTA dynamic records. The report selection contains 45 FULL windows, 45 DELTA zero-load windows and 15 DELTA dynamic windows.

## Contents

- `data/`: canonical recordings and per-condition records.
- `analysis/`: current selection, audits and derived statistics.
- `history/`: superseded or diagnostic campaigns retained for provenance.
- `figures/`: figure exports; only report-linked files are release material.
- `script/`: indexing and audit utilities.

Key indexes are `data/run_index.csv`, `data/primary_matrix.csv`, `data/dynamic_analysis_selected.csv` and `data/analysis_selected.csv`. Values and source files are unchanged by this organisation.

The neighbouring LaTeX source is excluded by its `.gitignore`.
