# Final data review snapshot

This directory records the final classification of the 114 current-campaign recordings. The derived indexes select 90 zero-load windows and 15 dynamic windows from five complete passing batches, with 105 records in their union. `evidence_review.json`, `final_verification.json`, `new_run_index.csv`, `path_map.csv` and `summary_snapshot.json` provide machine-readable provenance. `FINAL_SUMMARY_CN.md` is retained because the appendix names that path.

The active review files are aligned to the existing PDF. The former 111-record/102-selected snapshot is preserved in `history/superseded_111_102_20260913/`.

The source raw files remain under ../../data. This review directory contains audit outputs and selection evidence only.
