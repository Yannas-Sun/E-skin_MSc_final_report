# module_1

Module M1 contains two separately tested sensing layers:

| Folder | Purpose |
| --- | --- |
| FSR1/ | First 16×16 layer; independent sweep, endpoints, models, and validation records. |
| FSR2/ | Second 16×16 layer; independent sweep, endpoints, models, and validation records. |

Do not combine FSR1 and FSR2 records in one analysis condition. Each layer has its own calibration range, model identity, and validation population.
