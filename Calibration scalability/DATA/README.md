# DATA

This folder contains the source records and derived outputs used by the calibration report.

| Item | Purpose |
| --- | --- |
| module_1/ | M1 data; see its README for the layer split. |
| module_1/FSR1/ | Independent FSR1 training and validation package. |
| module_1/FSR2/ | Independent FSR2 training and validation package. |

Raw sweeps, validation captures, model copies, and published plots are kept under the relevant FSR directory. Generated files are described by the FSR README and the file patterns in the project-root README. Treat source records as read-only.
