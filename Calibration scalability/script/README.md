# Calibration scripts

The scripts implement the current paper workflow. Run them from the package root with python -B.

- Main/data_scalability_monitor.py — acquisition GUI and validation controls.
- Main/calibration_measurement.py — immutable model snapshots and 200-frame validation capture.
- Main/calibration_shared_endpoints.py — 22-point sweep and shared endpoint workflow.
- Main/Calibration/calibrate_fsr.py — endpoint-model generation from a saved sweep.
- Main/Model/plot_pressure_calibration_monotonic.py — per-cell monotonic fitting and response plots.
- Main/Model/plot_calibration_comparison.py — LINEAR, GAMMA, and FIT PRESS comparison plots; the Shared LUT comparator is generated by Main/Evaluation/shared_lut_baseline.py.
- Main/Evaluation/ — single-capture, cumulative error, dispersion, and preflight analysis.
- Main/Utility/ — portable paths and saturation-range helpers.
